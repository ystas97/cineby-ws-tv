# Cineby WS TV

TizenBrew site-modification module for Samsung TVs. It provides a custom 10-foot browsing interface with large posters, a featured panel, category navigation and directional remote control. It uses only title links and artwork already visible on the loaded page at https://cineby.ws/ and does not collect credentials or browsing data.

## Установка

1. Установите и запустите [TizenBrew](https://github.com/reisxd/TizenBrew).
2. Откройте **Module Manager → Add GitHub Module**.
3. Введите `ystas97/cineby-ws-tv` (после публикации репозитория).
4. Вернитесь в главное меню TizenBrew и запустите **Cineby WS TV**.

### TV Edition 1.5 — автообновление

- Модуль обновляется сам: при каждом открытии сайта он берёт последнюю версию из ветки main на GitHub. Удалять и добавлять модуль заново или перезагружать телевизор после обновлений больше не нужно; новая версия появляется в течение 5 минут после публикации.
- Перезагрузить телевизор нужно один раз — при переходе на 1.5, чтобы TizenBrew получил новый загрузчик.
- Пульт работает внутри встроенного плеера: кнопка «⚙ Quality · Subtitles» передаёт управление плееру, стрелки ходят по его кнопкам и меню (качество, субтитры, язык, скорость), OK выбирает. «Назад» закрывает открытое меню, а следующее «Назад» возвращает к панели модуля. Проверено на JW Player (сервер Neon) и на плеере сервера Nyx; остальные серверы обслуживаются тем же универсальным способом.
- Субтитры и варианты качества зависят от источника: если у сервера их нет (например, у Neon для части фильмов только «Off»), переключитесь на другой сервер кнопкой Server.

### TV Edition 1.4

- Play Now сразу запускает видео: модуль сам нажимает большую кнопку плеера сайта, второе нажатие OK не нужно.
- Плеер сразу открывается на весь экран, как в ТВ-приложениях. Панель управления поверх видео скрывается через несколько секунд; первое нажатие любой кнопки показывает её снова.
- Для встроенного плеера: OK передаёт управление самому плееру, кнопка Server переключает источник, если текущий не работает.
- Кнопка «Назад» закрывает плеер. Внешний плеер перехватывает все кнопки пульта, пока у него фокус, поэтому через 8 секунд модуль возвращает фокус себе, и «Назад» снова работает.

### TV Edition 1.3

- Главная открывается на каталоге /home, а не на приветственной странице.
- Главный экран: вертикальное меню, большой кинематографичный фон выбранного фильма, горизонтальные ряды обложек.
- Обложки берутся из оригинальной разметки страницы, включая ленивую загрузку, srcset и фоновые изображения.
- Movies / Series: крупная сетка, навигация по страницам и доступ к фильтрам.
- Search и Site view открывают оригинальные элементы сайта. Кнопка TV view возвращает новый интерфейс.
- Экран фильма и сериала: крупный заголовок, описание, фон. Play Now переводит фокус на оригинальную большую кнопку запуска видео; следующий OK нажимает её.
- Стрелки движутся по конкретным карточкам и рядам. OK открывает выбранный фильм; Back возвращает к предыдущей стадии и каталогу.
- Режим TV player увеличивает существующий оригинальный video или iframe. Для доступного HTML5-видео добавляются кнопки Play/Pause, перемотка и ползунок. Внешний iframe остаётся в исходном виде по умолчанию; увеличенный режим доступен отдельной кнопкой. Его внутренние органы управления остаются под управлением самого плеера.
- Если карточки не распознаны, модуль сохраняет исходную страницу как запасной вариант.

Для воспроизведения требуется, чтобы сайт и его плеер поддерживались браузером конкретного телевизора.

## Управление

| Кнопка | Действие |
|---|---|
| ↑ ↓ ← → | Переход к ближайшему элементу в указанном направлении |
| OK | Открыть ссылку, нажать кнопку или активировать поиск |
| Назад | Закрыть текстовый ввод / полноэкранный режим; в остальных случаях стандартное действие |
| Play/Pause | Пауза или продолжение доступного HTML5-видео |
| Fast Forward / Rewind | Вперёд / назад на 10 секунд |

Модуль автоматически обновляет список навигационных элементов после появления карточек и модальных окон.

## Ограничения

- Это независимый модуль, не официальный продукт Cineby или Samsung.
- Он не размещает фильмы и не изменяет ограничения доступа, DRM, рекламу, запросы или сетевые настройки сайта.
- Управление видео работает только для доступных HTML5-видео в текущем документе. Внешние iframe могут иметь собственные ограничения и управление.
- Сайт может менять структуру или адрес; совместимость необходимо проверять на конкретной модели ТВ. Используйте только контент и источники, к которым у вас есть право доступа.
- Модуль не требует отдельного сертификата: достаточно работающего TizenBrew.

## Разработка

Исходный код интерфейса — `tv.js`, без зависимостей и сборки. `embed.js` — управление пультом внутри встроенных плееров (TizenBrew выполняет модуль в каждом фрейме вкладки). `remote.js` — маленький загрузчик, который TizenBrew запускает на странице и во фреймах: он узнаёт у GitHub API последний коммит ветки main и подключает `tv.js` этого коммита через jsDelivr (идентификатор коммита кэшируется на 5 минут). Если GitHub недоступен, используется последний известный коммит, затем `@main`. `package.json` описывает модуль.

Обновление: достаточно отправить изменения `tv.js` в main. Если меняется сам `remote.js`, поставьте тег версии и сбросьте кэш jsDelivr для `remote.js` и `package.json`; на телевизоре потребуется перезагрузка.

```sh
npm test
```

Проверки покрывают геометрическую навигацию, коды клавиш, манифест, распознавание маршрутов и метаданных карточек. Есть также синтетические DOM-тесты главной, обложек, страницы фильма, запуска оригинального плеера и обратимого TV player. Физический телевизор нужен для проверки фактической работы с настоящим сайтом и встроенной клавиатурой.
