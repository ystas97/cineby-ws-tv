# Cineby WS TV

TizenBrew site-modification module for Samsung TVs. It provides a custom 10-foot browsing interface with large posters, a featured panel, category navigation and directional remote control. It uses only title links and artwork already visible on the loaded page at https://cineby.ws/ and does not collect credentials or browsing data.

## Установка

1. Установите и запустите [TizenBrew](https://github.com/reisxd/TizenBrew).
2. Откройте **Module Manager → Add GitHub Module**.
3. Введите `ystas97/cineby-ws-tv` (после публикации репозитория).
4. Вернитесь в главное меню TizenBrew и запустите **Cineby WS TV**.

### TV Edition 1.2

- Главная открывается на каталоге /home, а не на приветственной странице.
- Главный экран: вертикальное меню, большой кинематографичный фон выбранного фильма, горизонтальные ряды обложек.
- Обложки берутся из оригинальной разметки страницы, включая ленивую загрузку, srcset и фоновые изображения.
- Movies / Series: крупная сетка, навигация по страницам и доступ к фильтрам.
- Search и Site view открывают оригинальные элементы сайта. Кнопка TV view возвращает новый интерфейс.
- Экран фильма и сериала: отдельный крупный заголовок, описание, фон и кнопка Play, которая вызывает оригинальное действие сайта.
- Режим TV player увеличивает существующий оригинальный video или iframe. Для доступного HTML5-видео добавляются кнопки Play/Pause, перемотка и ползунок. Внешний iframe сохраняет собственные органы управления; возврат к исходной странице всегда доступен.
- Если карточки не распознаны, модуль сохраняет исходную страницу как запасной вариант.

Для воспроизведения требуется, чтобы сайт и его плеер поддерживались браузером конкретного телевизора.

## Управление

| Кнопка | Действие |
|---|---|
| ↑ ↓ ← → | Переход к ближайшему элементу в указанном направлении |
| OK | Открыть ссылку, нажать кнопку или активировать поиск |
| Назад | Закрыть текстовый ввод / полноэкранный режим; в остальных случаях стандартное действие |
| Play/Pause | Пауза или продолжение доступного HTML5-видео |
| Fast Forward / Rewind | Вперёд / назад на 10 секунд |

Модуль автоматически обновляет список навигационных элементов после появления карточек и модальных окон.

## Ограничения

- Это независимый модуль, не официальный продукт Cineby или Samsung.
- Он не размещает фильмы и не изменяет ограничения доступа, DRM, рекламу, запросы или сетевые настройки сайта.
- Управление видео работает только для доступных HTML5-видео в текущем документе. Внешние iframe могут иметь собственные ограничения и управление.
- Сайт может менять структуру или адрес; совместимость необходимо проверять на конкретной модели ТВ. Используйте только контент и источники, к которым у вас есть право доступа.
- Модуль не требует отдельного сертификата: достаточно работающего TizenBrew.

## Разработка

Исходный код — `remote.js`, без зависимостей и сборки. `package.json` описывает модуль.

```sh
npm test
```

Проверки покрывают геометрическую навигацию, коды клавиш, манифест, распознавание маршрутов и метаданных карточек. Есть также синтетические DOM-тесты главной, обложек, страницы фильма, запуска оригинального плеера и обратимого TV player. Физический телевизор нужен для проверки фактической работы с настоящим сайтом и встроенной клавиатурой.
